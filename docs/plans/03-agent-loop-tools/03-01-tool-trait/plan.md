# 03-1 `Tool` 트레이트 설계: 상세 기획

- 상태: 완료
- 상위 문서: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 목적
도구 7개가 한 트레이트에 모이는 틀을 정한다. 03-2(루프)·03-3(파일 도구)·03-6(run_command)·03-8(execute)이 같은 경로로 도구를 등록·실행하게 하는 것이 목적이다.

## 범위(In)
- `tools/tool.rs` 서명: 이름·설명·인자 JSON Schema·실행·승인 요청을 한 자리에 담는다.
- 등록 규칙: 트레이트 객체 하나를 OpenAI `tools` 배열 한 자리로 바꾸는 규칙을 정한다.
- 결과 규격: 문자열 한 개로 돌려주는 서명, 오류는 `오류: 이유` 한 줄로만 고인다.
- 자리: 승인자 인터페이스(`ApprovalRequired` 자리)와 경로 검사 헬퍼 이름을 정한다.
- 03-1은 문서 산출물만 만든다. 코드는 두지 않는다.

## 비범위(Out)
- 도구 구현(파일 도구·검색·셸): 03-3·03-6.
- 루프 구현: 03-2.
- 호출 형식 경로 선택(모델 프로필): 03-2·03-4.

## AC
1. `Tool` 트레이트 서명이 이 문서와 spec.md에 있고, 필드·메서드 이름이 정해진다.
2. 등록 규칙이 OpenAI `tools` 자리 한 개로 환원되는 예제가 spec.md에 있다.
3. `ToolContext`의 승인자 자리와 `ApprovalRequired`가 spec.md에 있다.
