# 03-9 (후보) timeout→백그라운드·주기 wake: 상세 기획

- 상태: planned (후보)
- 상위 문서: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md), 선행: [03-7](../03-07-process-tree/plan.md)

## 목적
실행 deadline이 만료된 명령을 끝내지 않고 백그라운드로 옮기고, 주기적으로 wake해 결과를 확인하는 후보 설계를 정한다.

## 범위(In)
- timeout→백그라운드 후보를 03에서 설계만 적는다. 구현 범위는 세부 작업 AC로 확정한다.
- 주기 wake 설정을 적는다. wake 간격과 확인 항목을 정한다.
- 03-6의 600초 deadline과 wake가 이어지는 경로를 확인한다.

## 비범위(Out)
- 백그라운드 명령이 대화형 세션에서 이어지는 상태 관리: 04 배치.
- L2·L3 자동화: 04 배치(D22).

## 선행 세부 작업
[03-7](../03-07-process-tree/plan.md).

## 참고 자료
- Prospero(RESEARCH Prospero 절): timeout→백그라운드는 후보.

## 리스크
백그라운드 명령의 승인·종료 코드를 모델이 받는 방식이 03-2 도구 호출과 겹친다. AC로 확정하기 전에는 03 범위 밖으로 둔다.
