# 03-9 (후보) timeout→백그라운드·주기 wake: 명세

- 상위 문서: [plan.md](plan.md), 상위 기획: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)
- 상태: 후보 — 착수 여부를 03 세부 기획에서 정한다. 이 명세는 설계 확정용 뼈대다.

## 입력과 출력
- 입력: 03-6 deadline 만료 이벤트, wake 주기 설정(초 단위).
- 출력: 백그라운드 등록 표시, wake마다 확인한 명령 상태(실행 중·완료·종료 코드).

## 동작 규칙 (설계안)
1. 실행 deadline(600초) 만료 시 명령을 종료하지 않고 백그라운드로 옮긴다.
2. wake 주기마다 표준 출력·표준 오류와 종료 코드를 확인한다.
3. 완료되면 그 결과를 도구 결과로 모델에 전달한다(03-2 경로).
4. wake 간격 기본은 30초, 설정으로 바꾼다.
5. 백그라운드 명령이 프로그램 종료 시 03-7 경로로 종료됨을 확인한다.

## AC (후보, 착수 시 확정)
1. deadline 만료 → 백그라운드 등록 → wake 완료 결과를 받는 왕복을 모의 명령으로 확인한다(테스트).
2. wake 전에는 결과를 모델에 알리지 않는다.
3. 프로그램 종료 시 백그라운드 트리가 03-7로 정리된다(테스트).
4. 검증 명령 3종 통과(공통 DoD).
