- [ ] 3. 03-6 deadline 만료를 백그라운드로 옮기는 경로를 만든다. 확인: 왕복 테스트(spec AC 1).
- [ ] 4. 완료 결과를 03-2 도구 결과로 전달한다. 확인: 모의 서버 테스트.

- [ ] 6. `docs/RESEARCH.md` 작업 03 절 적용 위치를 갱신한다.

## 테스트 계획
- OS 셸에서 확인이 어려운 명령은 "실행 미확인"으로 표기한다.
- wake 값은 짧게 주고, 경과 확인은 하한·상한으로만 한다.
