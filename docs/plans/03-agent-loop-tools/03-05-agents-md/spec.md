# 03-5 AGENTS.md 읽기 조립: 명세

- 상위 문서: [plan.md](plan.md), 상위 기획: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 입력과 출력
- 입력: 작업 폴더에 있는 `AGENTS.md` 파일.
- 출력: 03-2 시스템 프롬프트에 조립된 프로젝트 지시 문자열. 파일이 없으면 지시 없는 상태.

## 동작 규칙
1. 작업 폴더 최상위의 `AGENTS.md`를 읽는다. 파일 이름 비교는 그 OS의 대소문자 관례를 따른다.
2. 파일이 없으면 지시 없이 진행한다(오류가 아니다).
3. 파일이 있으면 03-2의 짧은 시스템 프롬프트 뒤에 이어 붙인다(2307.03172: 지시는 앞머리에 둔다).
4. 읽은 내용은 원문 그대로 넣고 잘라 넣지 않는다.
5. 파일이 비면 지시 없는 상태다.
6. 읽기 실패(권한·깨진 링크)는 "읽기 실패"를 표시하고 지시 없이 진행한다(루프는 계속 돈다).

## AC (상위 AC 6과 연결)
1. `AGENTS.md`가 있으면 시스템 프롬프트가 짧은 규범 뒤에 AGENTS.md 원문으로 조립된다(테스트).
2. `AGENTS.md`가 없으면 지시 없이 루프가 돌아간다(테스트).
3. 파일이 비거나 읽기 실패면 지시 없는 상태로 표시하고 루프가 계속 돈다(테스트).
4. 검증 명령 3종 통과(공통 DoD).
