# 03-10 단발 run·작업 명세·검증 명령·스모크: 상세 기획

- 상태: planned
- 상위 문서: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md), 선행: [03-6](../03-06-run-command/plan.md)

## 목적
`agent-snap run "<과제>"` 단발 실행을 만들고, 작업 명세 규칙과 검증 명령 확인을 붙이며, 실제 엔드포인트 스모크 기록을 남긴다.

## 범위(In)
- `run` 커맨드: 사용자 원문을 보존한 작업 명세를 만들고 목표·입력·완료 조건만 더 담는다.
- `--model <이름>` 지정, 미지정 시 설정 목록에서 고름. 입력을 받을 수 없으면 모델 이름 목록 오류로 끝낸다.
- 작업 명세 완료 조건의 검증 명령을 에이전트 종료 뒤 실행하고, 실패하면 0이 아닌 종료 코드와 이유를 낸다.
- 스모크: 실제 엔드포인트로 과제 3개(파일 만들기, 수정, 테스트 실행)를 수행한 기록을 `docs/reports/03-smoke.md`에 남긴다. (a) 기능 목록 대조 결과를 같은 파일에 남긴다(D43 DoD).
