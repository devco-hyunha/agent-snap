# 03-10 단발 run·작업 명세·검증 명령·스모크: 명세

- 상위 문서: [plan.md](plan.md), 상위 기획: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 입력과 출력
- 커맨드 입력: `agent-snap run "<과제>"`, `--model <이름>` 선택.
- 커맨드 출력: 에이전트가 수행한 결과 요약, 검증 명령 종료 코드, 실패 시 0이 아닌 종료 코드와 이유.
- 스모크 입력: 설정된 실제 엔드포인트, 과제 3개(파일 만들기, 수정, 테스트 실행).
- 스모크 출력: `docs/reports/03-smoke.md` 기록.

## 동작 규칙

### 작업 명세 (AC 6)
1. 사용자 원문을 그대로 보존하고 목표·입력·완료 조건만 더 담는다.
2. 완료 조건에 검증 명령이 있으면 에이전트가 끝난 뒤 03-6 `run_command`로 실행한다.
3. 검증 명령 종료 코드가 0이 아니면 0이 아닌 종료 코드와 이유를 낸다.
4. `--model` 지정 시 그 모델로 실행한다. 미지정 시 설정 목록에서 고르고, 입력을 받을 수 없으면 모델 이름 목록 오류로 끝낸다.

### 스모크 기록 (AC 3)
1. `docs/reports/03-smoke.md`에 3개 과제 수행 기록을 남긴다.
2. URL과 키는 기록에 넣지 않는다.
3. [기능 목록](../../../research/agent-feature-inventory-2026-11-07.md) (a) 7개 도구 사용 여부와 04 배치 항목 넘김 여부를 같은 파일에 남긴다(D43 DoD).

## AC (상위 AC 3·4·6·7과 연결)
1. 작업 명세에 사용자 원문이 보존되고 목표·입력·완료 조건만 담김을 테스트로 확인한다.
2. 완료 조건 검증 명령을 에이전트 종료 뒤 실행하고, 실패 시 0이 아닌 종료 코드와 이유를 낸다(모의 서버 테스트).
3. `--model` 지정·미지정 동작과 모델 목록 오류를 테스트로 확인한다.
4. `docs/reports/03-smoke.md`에 과제 3개 기록과 (a) 대조 결과가 있다.
5. 검증 명령 3종 통과(공통 DoD).
