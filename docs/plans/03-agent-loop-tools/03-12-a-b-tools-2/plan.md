# 03-12 (a)(b) 배치 이관 2차: 웹 도구·체크포인트

- 상태: planned

- 근거: [기능 목록](../../../research/agent-feature-inventory-2026-11-07.md) (a) 웹 검색·열람, (b) 체크포인트, DECISIONS D43 2차 개정(2026-11-09).

## 목적
웹 도구(`web_search`·`web_fetch`)와 체크포인트(git 연동)를 03에 넣는다. 도구는 03의 `Tool` 경로와 승인 게이트를 그대로 지난다.

## 범위(In)
- `web_search`: 설정에 등록된 검색 엔진 키(엔드포인트 목록 활용)로 검색하고 결과를 한 줄 요약 목록으로 돌려준다.
- `web_fetch`: URL(주소)을 열어 본문 텍스트를 따서 전달한다(03-2 잘림 규칙 재사용).
- 체크포인트: 도구 실행 전 작업 폴더 상태를 git 커밋으로 남기고, 되돌리기 요청 시 커밋 단위 복구를 안내한다.

## 비범위(Out)
- 검색 엔진 전용 키 체계 확장(새 설정 키는 04 확장 항목으로 이관).
- 브라우저 자동화(스크린샷·자바 스크립트 실행 등 무거운 경로)는 넣지 않는다.

## AC
1. 모의 서버로 검색 요청→결과 목록 전달을 테스트로 확인한다.
2. `web_fetch` 결과가 4,000자 잘림 규칙을 따름을 테스트로 확인한다.
3. 체크포인트 커밋이 작업 폴더에 남고, 승인 거부 시 커밋이 남지 않음을 확인한다.
4. 검증 명령 3종 통과.

## 리스크
- 외부 통신(웹)은 02-6 전송 재시도 규칙(D13)과 겹치지 않게 한 층에서만 재시도한다.
- 웹 본문에 키·주소가 섞여 나올 수 있다. 가리기 규칙(D28)을 결과에 적용한다.
