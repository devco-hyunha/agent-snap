## 목적
심볼 단위 조회 도구 1차, 훅 연결 지점, MCP 연결 골격을 03에 넣는다. 04 확장으로 넘기던 (a)(b)(i)(j) 잔여를 03에서 마무리한다.

## 범위(In)
- 심볼 조회 1차: 함수·구조·심볼 이름으로 파일 내 위치를 찾는 `find_symbol` 도구. 백엔드는 rust-analyzer 등 LSP 서버를 `Tool` 경로로 감싼다.
- 훅 연결 지점: 05 `Monitor` 트레이트가 훅을 걸 수 있는 지점(호출 전·결과 후 한 줄 훅)을 인터페이스로 남긴다.
- MCP 연결 골격: MCP 서버의 도구 목록을 `Tool` 등록 목록에 붙이는 자리. 등록 시 승인·작업 폴더 경계 규칙을 같은 경로로 적용한다.

## 비범위(Out)
- 심볼 편집·이름 바꾸기 2차. 06 이후 판단.
- 훅 스크립트 실행 규칙·규칙 감시: 05.
- MCP 서버 자체 구현·포함: 제품 확장. Serena(MCP)를 붙이지 않고 D33 정본대로 네이티브 `Tool`로만 구현한다(동작 참고만, 의존 금지).

## AC
1. `find_symbol`이 설정에 등록한 백엔드에서 심볼 위치 목록을 반환하는 것을 테스트로 확인한다.
2. 훅 연결 지점(인터페이스)이 루프의 왕복마다 기록되는 것을 단위 테스트로 확인한다.
3. MCP 등록 도구가 `Tool` 목록에 붙고 같은 승인 규칙을 지나는 것을 확인한다.
4. 검증 명령 3종 통과.

## 리스크
