# 03-2 에이전트 루프: 상세 기획

- 상태: 계획
- 상위 문서: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 목적
모델이 도구를 부르고 결과를 받아 다음을 짓는 루프를 만든다. 02가 만든 클라이언트를 그대로 재사용하고, 도구를 `Tool` 트레이트로 분리한다. 루프는 02-6(재시도 한 층, D13)과 중복 재시도하지 않는다.

- (메모 2026-11-08·갱신) 호출 형식은 "OpenAI 1안 단독"이 아니라 3형식 조합으로 확정했다(2026-11-08 사용자 결정). 1안 OpenAI `tools`/`tool_calls`를 기본 경로로 유지하고, 2안 텍스트 프로토콜을 로컬 미지원 모델 폴백으로 03-4에 분리하며, 3안 코드 모드(execute)는 도구 브리지로 03-8(신규)에 둔다. 근거: [12번 문서](../../../research/12-tool-calling-forms.md). 확정 기록은 DECISIONS D46(예정)로 남긴다.

## 범위(In)
- `Tool` 트레이트: 이름·설명·인자 형식(JSON)·실행 한 자리를 갖춘다. 도구는 구현 하나당 파일 하나(PROJECT_RULES 개발 규칙).
- 루프: 요청 전송 → `finish_reason=tool_calls`이면 도구 실행 → 도구 결과를 messages에 추가 → 계속 전송 → `finish_reason=stop`이면 종료.
- 반복 상한과 종료 조건: 상한 초과, 미승인·거부 결과, 모델이 도구 호출을 못 하는 경우를 나누어 끝낸다.
- 도구 인자 JSON: 해석, 깨진 JSON은 복구 시도, 실패하면 짧은 오류를 도구 결과로 돌려준다.
- 도구 호출 턴 낮은 온도: 설정에 `tool_call` 프로파일을 두고 모델의 `extra`로 합쳐 보낸다(D15).
- 도구 출력이 길면 잘라 전달한다.
- 짧은 시스템 프롬프트: 불변 규범을 `agent/system_prompt.txt`에 담는다.
