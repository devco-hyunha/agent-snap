# 03-3 파일 도구·glob·grep·list_dir: 명세

- 상위 문서: [plan.md](plan.md), 상위 기획: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 입력과 출력
- read_file: 입력 경로(·opt 시작 줄 `offset`·읽을 줄 수 `limit`). 출력 텍스트(줄 번호 표기 포함, 잘림 표시 가능).
- write_file: 입력 경로·내용. 출력 성공 표시·쓰기 위치·덮어쓰기 표시.
- edit_file: 입력 경로·찾을 문자열·바꿀 문자열. 출력 성공 또는 실패 이유.
- list_dir: 입력 경로(opt 하위 포함). 숨김 항목은 기본 제외(opt로 포함). 출력 항목 목록.
- glob: 입력 패턴·경로 opt(기본 작업 폴더). 숨김 항목은 기본 제외(opt로 포함). 출력 경로 목록.
- grep: 입력 패턴·경로 opt·대소문자·확장자 필터·출력 형식 3종(content·files·count). 출력 매칭.

## 동작 규칙

### 경로 검증 (AC 2)
- 경로가 작업 폴더 안이 아니면 거부("경계 밖" 이유와 함께).
- `..`가 포함된 상대 경로는 경로 정규화 후 검사한다.
- 심볼릭 링크가 작업 폴더 밖으로 나가는 경로를 가리키면 거부.
- 작업 폴더 밖에 절대 경로를 지정하면 거부.
- 파일 목록·검색 결과가 작업 폴더 밖 경로를 내보내지 않는다.

### 파일 형식·크기 (AC 5, D49)
- read_file 기본 텍스트. 바이너리로 보이면 읽지 않고 "바이너리" 이유.
- 기본 읽기 크기 상한: 256KB 이상이면 읽지 않고 이유.
- 텍스트 읽기: 잘림 표시. 기본은 앞 128KB만 읽는다.
- 출력 잘림은 03-2과 같은 규칙: `…[truncated]`을 붙이고 앞 부분만 전달. 모델에 넘기는 결과는 기본 읽기·구간 읽기 모두 4,000자 상한을 적용한다(D49 3층).
- 긴 파일은 `offset`·`limit` 구간 읽기가 공식 경로다. 256KB 넘는 파일도 구간을 지정하면 읽을 수 있고, 구간은 페이지당 50KiB 이하만 허용한다.
- 기본 읽기를 거부할 때 결과에 "offset·limit으로 구간을 읽거나 grep으로 검색하라"는 안내를 담는다.

### edit_file (AC 3)
- 찾을 문자열이 정확히 하나 일치할 때만 바꿀 문자열로 교체한다.
- 찾을 문자열이 없으면 "일치 없음" 이유.
- 둘 이상 일치하면 "다중 일치" 이유와 교체하지 않음.
- 바꿀 문자열이 찾을 문자열과 같아도 일치가 1개면 성공이고 파일은 그대로다.
- 쓰기는 승인 대상이 아니다(D49). 교체 결과를 결과 표시로 알린다.

### 비밀 파일 차단 (AC 2, D17)
- 사용자 설정 폴더 아래와 작업 폴더(하위 포함)의 `agent-snap.jsonc`·`credentials.jsonc`를 읽기·쓰기·목록·검색 결과에서 거부·차단한다.
- `.env` 계열(`.env`, `.env`로 시작하는 파일)도 같은 규칙으로 차단한다(Claude Code 비밀 유출 사건 2611-GitGuardian 교훈, 2026-11-10 T4). `.env.local`처럼 `.env`로 시작하는 파일까지 포함한다.
- `run_command` 경로 검사도 03-6가 담당한다.
- 비밀 파일 이름은 경로 정규화로 비교한다(대소문자 OS 관례).

### grep·glob (AC 2, AC 5, D49)
- ripgrep가 있으면 ripgrep 경로로 검색하고, 없으면 내장 검색.
- 결과는 형식 3종(content·files·count) 모두에서 최대 200줄, 초과 시 잘림 표시.
- 목록·검색 결과에 비밀 파일 경로가 없음을 테스트로 확인.
- 검색 결과가 길면 03-2과 같은 잘림 규칙을 쓴다.
- list_dir·glob은 숨김 항목을 기본으로 제외하고, opt로 포함한다.

### 경로 검증 검사 순서 (AC 2, T3 확정)
- 검사 순서를 한 곳에서 고정한다: 경로 정규화 → 작업 폴더 경계 → 심볼릭 링크 → 비밀 목록.
- T1이 만드는 1차는 정규화 → 경계 → 비밀 순서이고, T3가 심볼릭 링크 검사를 자리에 추가해 위 순서로 확정한다.
- 모든 파일 도구가 같은 경로를 호출하고, 도구 파일마다 검사를 다시 정의하지 않는다.

## AC (상위 AC 2·5와 연결)
1. read_file이 잘림 표시로 잘린 텍스트와 "읽기 한도 초과" 표시를 돌려준다.
   - 1a. 256KB 넘는 파일도 `offset`·`limit` 구간(50KiB 이하)이면 읽고, 구간 읽기 결과도 4,000자 잘림을 적용하며, 기본 읽기 거부 시 안내(`offset`·`limit`·grep)가 결과에 남는다(D49, 테스트).
2. 작업 폴더 밖 경로(read_file·write_file·edit_file·list_dir·glob·grep)는 "경계 밖"으로 거부한다.
3. edit_file이 일치·다중 일치를 테스트로 확인한다.
4. write_file·read_file·list_dir·glob·grep 결과와 오류가 비밀 파일(`agent-snap.jsonc`·`credentials.jsonc`)을 노출하지 않는다.
5. grep 결과는 최대 200줄 상한을 두고, 넘으면 앞 200줄 뒤에 잘림 표식(`…[truncated]`)을 붙인다.
6. glob·grep 결과가 작업 폴더 밖 경로를 내보내지 않는다.
7. 검증 명령 3종 통과(공통 DoD).
8. (T4) `.env`와 `.env`로 시작하는 파일(`.env.local` 등)을 read_file·write_file·list_dir·glob·grep에서 차단하고, 결과·오류에 경로를 내보내지 않음을 테스트로 확인한다.
