# 03-3 파일 도구·glob·grep·list_dir: 명세

- 상위 문서: [plan.md](plan.md), 상위 기획: [../../03-agent-loop-tools.md](../../03-agent-loop-tools.md)

## 입력과 출력
- read_file: 입력 경로(·opt 오프·제한). 출력 텍스트(줄 번호 표기 포함, 잘림 표시 가능).
- write_file: 입력 경로·내용. 출력 성공 표시·쓰기 위치.
- edit_file: 입력 경로·찾을 문자열·바꿀 문자열. 출력 성공 또는 실패 이유.
- list_dir: 입력 경로(opt 하위 포함·숨김 표시 규칙). 출력 항목 목록.
- glob: 입력 패턴·경우 opt(기본 작업 폴더). 출력 경로 목록.
- grep: 입력 패턴·경로 opt·대소문자·확장자 필터·출력 형식 3종(content·files·count). 출력 매칭.

## 동작 규칙

### 경로 검증 (AC 2)
- 경로가 작업 폴더 안이 아니면 거부("경계 밖" 이유와 함께).
- `..`가 포함된 상대 경로는 경로 정규화 후 검사한다.
- 심볼릭 링크가 작업 폴더 밖으로 나가는 경로를 가리키면 거부.
- 작업 폴더 밖에 절대 경로를 지정하면 거부.
- 파일 목록·검색 결과가 작업 폴더 밖 경로를 내보내지 않는다.

### 파일 형식·크기 (AC 5)
- read_file 기본 텍스트. 바이너리로 보이면 읽지 않고 "바이너리" 이유.
- 기본 읽기 크기 상한: 256KB 이상이면 읽지 않고 이유.
- 텍스트 읽기: 잘림 표시. 기본 앞 128KB 앞을 읽는다.
- 출력 잘림은 03-2과 같은 규칙: `…[truncated]`을 붙이고 앞 부분만 전달.

### edit_file (AC 3)
- 찾을 문자열이 하나만 일치하면 교체.
- 찾을 문자열이 없으면 "일치 없음" 이유.
- 여러 개 일치하면 "다중 일치" 이유와 교체하지 않음.
- 일치가 1개인 경우에만 교체.
- 바꿀 문자열이 찾을 문자열과 같으면 성공이고 변경 없다.

### 비밀 파일 차단 (AC 2, D17)
- 사용자 설정 폴더 아래와 작업 폴더(하위 포함)의 `agent-snap.jsonc`·`credentials.jsonc`를 읽기·쓰기·목록·검색 결과에서 거부·차단한다.
- `run_command` 경로 검사도 03-6가 담당한다.
- 비밀 파일 이름은 경로 정규화로 비교한다(대소문자 OS 관례).

### grep·glob (AC 2, AC 5)
- ripgrep가 있으면 ripgrep 경로로 검색하고, 없으면 내장 검색.
- 결과는 최대 200줄, 초과 시 잘림 표시.
- 목록·검색 결과에 비밀 파일 경로가 없음을 테스트로 확인.
- 검색 결과가 길면 03-2과 같은 잘림 규칙을 쓴다.

## AC (상위 AC 2·5와 연결)
1. read_file이 잘림 표시로 잘린 텍스트와 "읽기 한도 초과" 표시를 돌려준다.
2. 작업 폴더 밖 경로(read_file·write_file·edit_file·list_dir·glob·grep)는 "경계 밖"으로 거부한다.
3. edit_file이 일치·다중 일치를 테스트로 확인한다.
4. write_file·read_file·list_dir·glob·grep 결과와 오류가 비밀 파일(`agent-snap.jsonc`·`credentials.jsonc`)을 노출하지 않는다.
5. grep의 결과 최대 200줄, 잘림 표시.
6. glob·grep 결과가 작업 폴더 밖 경로를 내보내지 않는다.
7. 검증 명령 3종 통과(공통 DoD).
