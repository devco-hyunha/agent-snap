# 02-9 설정 저장: 명세

- 상태: 완료 (기획 승인 2026-11-28. AC 1~7 구현·시험으로 확인. 작업 단위 전체 리뷰 r1 미달 → 보정 → r2 미달(minor 1) → HARNESS 9절로 메인 보정 후 닫음)
- 상위 문서: [plan.md](plan.md)
- 선행 결정: 6번(직렬화), 19번(자동 발견 저장 인계), 20번(`context_window` 규칙)

## 입력과 출력

- 입력: 설정 폴더 경로, 연산 요청(엔드포인트·모델·키 추가·수정·삭제).
- 출력: 설정 파일 `snap.jsonc`와 자격 파일 `credentials.jsonc`에 반영된 텍스트. 주석·공백·정렬은 보존.
- 실패: 저장 직전 검증 통과 실패, 파일 교체 실패, 폴더 생성 실패 → 경로만 밝힌 저장 오류.

## 동작 규칙

### 저장 골격 (T1)

- 편집은 `jsonc-parser`의 `cst` 기능으로 한다. 주석·공백·정렬을 유지하고 값만 고른다.
- 쓰기는 원본 폴더에 임시 파일을 만들고 원본과 교체한다. 설정 폴더가 없으면 만든다. copy 대체 경로는 두지 않는다.
- 교체 실패 시 원본은 그대로 두고 저장 오류로 밝힌다. 오류에는 경로만 담고 키·주소 값은 담지 않는다.
- 파일 전체를 통째로 갈아쓰는 창구는 두지 않는다.

### 엔드포인트 연산 (T2)

- 추가: 엔드포인트 이름·주소·`kind`를 받아 `endpoints` 배열에 항목을 더한다. 키 칸은 설정에 두지 않는다.
- 수정: 같은 이름 항목을 찾아 주소·`kind`를 바꾼다. 다른 항목은 건드리지 않는다.
- 삭제: 같은 이름 항목을 배열에서 제거한다.
- 저장 직전에 `check_config`를 통과해야만 쓴다.

### 모델 연산 (T3)

- 엔드포인트 이름과 모델 이름 기준으로 `endpoints[].models` 안 항목을 추가·수정·삭제한다.
- `context_window`를 설정에 쓸 때는 1 이상 정수만 쓴다(결정 20번).
- 저장 직전에 `check_config`를 통과해야만 쓴다.

### 키 연산 (T4)

- 엔드포인트 이름 기준으로 자격 파일의 `api_keys` 표에 키를 추가·수정·삭제한다.
- 키 값은 `credentials.jsonc`에만 쓴다. `snap.jsonc`에는 키 칸을 만들지 않는다.
- 자격 파일이 없으면 최상위 `api_keys` 객체를 가진 파일로 새로 만든다.
- 저장 직전에 자격 구조 검사를 통과해야만 쓴다.

## 오류 종류와 담는 것

| 오류 | 담는 것 | 담지 않는 것 |
|---|---|---|
| 검증 실패로 저장 거부 | 기존 검증 오류(설정 규칙별) | 입력 값, 키, 주소 |
| 파일 교체 실패 | 파일 경로 | 키, 주소, 파일 내용 |
| 폴더·파일 생성 실패 | 경로 | 키, 주소 |
| 대상 항목을 찾지 못함 | 엔드포인트·모델 이름 | 키, 주소 |

## AC

1. Given 엔드포인트가 없는 설정 파일일 때, When 엔드포인트 추가를 부르면, Then 그 엔드포인트가 추가되고 다시 읽었을 때 보인다.
2. Given 사용자가 단 주석이 있는 파일일 때, When 엔드포인트·모델·키 연산을 부르면, Then 주석과 손대지 않은 항목이 그대로 남는다.
3. Given 같은 이름 엔드포인트가 있을 때, When 수정을 부르면, Then 그 항목만 바뀌고 다른 항목은 그대로다.
4. Given 모델이 있는 엔드포인트에서 모델 추가·수정·삭제를 부르면, Then `endpoints[].models` 안 항목만 바뀐다.
5. Given 키 추가를 부르면, Then 키 값이 `credentials.jsonc`에만 쓰이고 `snap.jsonc`에는 키 칸이 없다.
6. Given 검증에 걸리는 값으로 저장을 부르면, Then 저장이 거부되고 원본 파일이 그대로다.
7. Given 설정 파일·자격 파일·폴더가 없을 때, When 저장을 부르면, Then 파일과 폴더가 새로 만들어진다.

## 시험 계획

- `crates/snap-core/tests/`에 저장 시험 트리를 새로 두고, 임시 폴더 왕복·주석 보존·거부·가리기 시험을 관심사별로 나눈다.
- 재료는 문자열로 만든 설정·자격 텍스트를 쓰고, 네트워크는 쓰지 않는다.
- 원본 보존 확인은 파일 내용 문자열 비교로 한다.
- OS별 실경로 확인은 Windows·WSL 양쪽에서 같은 책임을 확인한다.
