# 02-1 비밀 값 래퍼와 자격 파일 읽기: 명세

- 상위 문서: [plan.md](plan.md)

## 입력과 출력
- 비밀 값 래퍼
  - 입력: 문자열 값.
  - 출력: 값을 명시적으로 꺼내는 경로로만 원문이 나온다. Debug와 Display로 찍으면 값 대신 가림 표시가 나온다.
- 자격 파일 읽기
  - 입력: 자격 파일의 텍스트(파일이 없으면 없음).
  - 출력: 엔드포인트 이름별 비밀 값 목록. 파일이 없으면 빈 목록. 해석에 실패하면 오류.
- 키 찾기
  - 입력: 엔드포인트 이름, 자격 파일에서 읽은 이름별 값.
  - 출력: 그 이름의 비밀 값. 못 찾으면 "없음"(오류가 아니다).

## 동작 규칙

### 자격 파일 형식 (D10)
- 형식은 JSONC다. 주석(`//`, `/* */`)과 마지막 쉼표를 허용한다.
- 최상위는 객체이고 `api_keys` 객체 아래에 `"<엔드포인트 이름>": "<키>"`를 둔다. `api_keys` 밖의 최상위 항목은 읽지 않고 무시한다.
- `api_keys`가 없거나 비어 있으면 키가 하나도 없는 것이다(오류 아님).
- 이름은 적힌 그대로 쓰며 대소문자와 `-`·`_`를 서로 다른 글자로 본다(D10).

### 거부
- `api_keys` 아래 값이 문자열이 아니면 그 엔드포인트 이름만 밝힌 오류로 거부한다. 값은 담지 않는다.
- `api_keys` 자체가 객체가 아니면 거부한다(담는 것 없음).
- JSONC 문법 오류는 줄 번호만 알린다. 줄 내용과 값은 담지 않는다.

### 키 찾기
- `api_keys`에 그 이름이 있고 값이 빈 문자열이 아니면 그 값을 돌려준다.
- 이름이 없거나 값이 빈 문자열이면 "없음"을 돌려준다(D14).
- 자격 파일이 없으면 "없음"이다.
- 엔드포인트의 `api_key` 칸 거부는 [02-2](../02-2-config/spec.md)가 한다.

## 오류 종류와 담는 것
| 오류 | 담는 것 | 담지 않는 것 |
|---|---|---|
| JSONC 문법 오류 | 줄 번호 | 줄 내용, 값 |
| 키 값이 문자열이 아님 | 엔드포인트 이름 | 값 |
| `api_keys`가 객체가 아님 | 오류 종류 | 값 |
- 모든 오류의 Display와 Debug에 키 값이 없다.
- 비밀 값 래퍼는 Debug와 Display에서 값을 가린다.

## 기본값
없음. 자격 파일 위치는 [02-2](../02-2-config/spec.md)의 사용자 설정 폴더 규칙을 따른다.

## AC
1. Given 주석과 마지막 쉼표가 든 자격 파일에 `api_keys`가 있을 때, When 읽고 이름으로 찾으면, Then 그 이름의 값이 나온다. 이름이 없거나 값이 빈 문자열이면 '없음'이고, 대소문자나 `-`·`_`만 다른 이름은 서로 다른 이름이다.
2. Given 자격 파일이 없을 때, When 읽으면, Then 오류가 아니라 키가 하나도 없는 상태이고 어느 이름을 찾아도 '없음'이다.
3. Given `api_keys` 아래 값이 문자열이 아닌 항목이 있을 때, When 읽으면, Then 그 엔드포인트 이름만 밝힌 오류로 거부하고 값은 오류에 없다.
4. Given JSONC 문법이 틀린 자격 파일일 때, When 읽으면, Then 줄 번호만 담은 오류이고 줄 내용과 값이 없다.
5. 비밀 값의 Debug·Display와 이 세부 작업의 모든 오류의 Display·Debug에 키 값이 없다(테스트).
