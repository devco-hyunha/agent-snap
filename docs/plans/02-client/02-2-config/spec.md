# 02-2 설정 읽기와 검증: 명세

- 상위 문서: [plan.md](plan.md)

## 입력과 출력
- 설정 읽기
  - 입력: 사용자 설정 폴더 경로. 폴더 안의 `agent-snap.jsonc`를 읽는다. 주석(`//`, `/* */`)과 마지막 쉼표를 허용한다.
  - 출력: 검증을 통과한 설정(언어, 엔드포인트 목록, 모델 목록, 샘플링 기본값, 시간·재시도 값). 실패하면 설정 오류.
- 키 정하기
  - 입력: 검증된 엔드포인트, 자격 파일 `credentials.jsonc`에서 읽은 이름별 값([02-1](../02-1-secrets/spec.md), 자격 파일이 없으면 없음).
  - 출력: 그 엔드포인트의 비밀 값 또는 "키 없음".
- 사용자 설정 폴더 위치 계산
  - 입력: 운영체제 관례에 필요한 환경 정보(주입받는다).
  - 출력: 폴더 경로. Windows는 Roaming AppData 아래 `agent-snap`, 그 밖은 XDG 관례를 따른다. 읽기 기능과 나눠 둬서 폴더 경로를 직접 줄 수 있다.
- `agent-snap.example.jsonc`: 자리표시자만 담은 예시 파일. 읽으면 검증을 통과한다.

## 설정 항목
- `target_language`: 기본 `ko`.
- 엔드포인트(D10): `name`, `base_url`(`/v1`까지 포함한 주소, 비밀 값 래퍼로 담음), `kind`(`openai`, `openrouter`, `ollama`, `vllm`, `llamacpp`, `lmstudio` 중 하나). 키 칸(`api_key`)과 키 환경 변수 이름을 가리키는 칸은 없다.
- 모델: `name`, 서버에 보낼 `id`, 쓸 엔드포인트 이름, 모델별 샘플링, 선택 `reasoning`(`off`, `low`, `medium`, `high`), 선택 `extra`(D15).
- `extra`: 공통 옵션에 없는 값을 하위 객체까지 담는 객체. 요청 본문에 합치는 일은 [02-5](../02-5-transport/spec.md)가 한다.
- `sampling`: 샘플링 기본값. 모델별 값이 있으면 모델별 값이 앞선다(적용은 [02-7](../02-7-model-select/spec.md)).
- 지원하는 샘플링 항목은 `temperature`, `top_p`, `max_tokens` 세 가지다(D14).
- `http`: 시간·재시도 값.

## 기본값
- `target_language`: `ko`.
- `reasoning`, `extra`: 없으면 요청에 아무것도 더하지 않는다.
- 샘플링: 모델별 값과 `sampling` 어디에도 없는 항목은 기본값을 두지 않는다. 요청 본문에서 빼서 서버 기본값을 따른다(D14).
- `http`(설정으로 바꿀 수 있고, 빠지면 아래 값이 된다)
  - 재시도 3회
  - 백오프 1~30초
  - `Retry-After` 상한 60초
  - 연결 10초
  - 헤더 대기 300초
  - 스트림 유휴 120초

## 동작 규칙
정상
- 정상 설정을 읽으면 엔드포인트, 모델, 샘플링, 시간 값이 읽힌다.
- 빠진 값은 위 기본값이 된다.
- 자격 파일에 이름이 없는 엔드포인트를 허용한다(키가 필요 없는 로컬 서버).
- 모델 이름과 서버에 보낼 id는 서로 다를 수 있다.

키 정하기(D10)
- 자격 파일 `api_keys`에 그 엔드포인트 이름이 있고 빈 문자열이 아니면 그 키를 쓴다. 이름은 적힌 그대로 쓰며 대소문자와 `-`·`_`를 구분한다.
- 이름이 없거나 빈 문자열이거나 자격 파일이 없으면 "키 없음"이다. 이때 요청은 Authorization 헤더 없이 간다([02-5](../02-5-transport/spec.md)).

경계
- `temperature`는 0 이상 2 이하, `top_p`는 0 초과 1 이하, `max_tokens`는 1 이상 정수여야 한다(D14).
- 엔드포인트 이름은 비어 있지 않은 문자열이어야 한다. 자격 파일의 키 이름으로 적힌 그대로 쓰이므로 그 밖의 형식 제한은 없다.
- 설정 폴더 경로를 받아 읽는 기능은 폴더 위치 계산과 독립이라 임시 폴더로 시험할 수 있다.

거부(이름만 밝힌 오류)
- 엔드포인트에 `api_key` 칸이 있는 경우: 값은 읽지도 출력하지도 않고, 엔드포인트 이름과 "키는 credentials.jsonc에 둔다"는 안내만 담은 설정 오류로 거부한다(D10).
- 엔드포인트 이름이 중복된 경우. 정확히 같은 문자열일 때만 중복이다(`Local`과 `local`은 서로 다르다).
- 모델 이름이 중복된 경우.
- 존재하지 않는 엔드포인트 이름을 가리키는 모델.
- `kind`가 지원하는 여섯 값이 아닌 경우: 엔드포인트 이름만 밝히고 값은 출력하지 않는다.
- `reasoning`이 네 값이 아닌 경우: 모델 이름만 밝힌다.
- `extra`에 클라이언트가 채우는 키(`model`, `messages`, `stream`, `tools`)가 있는 경우: 모델 이름과 그 키 이름만 밝힌다(D15).
- JSONC 문법 오류: 줄 번호만 알린다.
- 샘플링 항목이 범위를 벗어난 경우: 항목 이름과 모델(`sampling`이면 "기본") 이름만 밝혀 거부한다. 값은 출력하지 않는다(D14).
- 지원하지 않는 샘플링 항목: 항목 이름만 밝혀 거부한다(D14).

## 오류 종류와 담는 것
| 오류 | 담는 것 | 담지 않는 것 |
|---|---|---|
| 엔드포인트 이름 중복, 빈 이름 | 엔드포인트 이름 | base_url, 키 |
| 엔드포인트에 `api_key` 칸 있음 | 엔드포인트 이름, 안내 문구 | `api_key` 값, base_url |
| 모델 이름 중복 | 모델 이름 | id, 주소, 키 |
| 없는 엔드포인트 참조 | 모델 이름과(또는) 엔드포인트 이름 | 주소, 키 |
| `kind` 값 오류 | 엔드포인트 이름 | 입력 값, 주소, 키 |
| `reasoning` 값 오류 | 모델 이름 | 입력 값, 주소, 키 |
| `extra` 예약 키 | 모델 이름, 예약 키 이름 | `extra`의 값, 주소, 키 |
| JSONC 문법 오류 | 줄 번호 | 줄 내용, 값 |
| 샘플링 범위 벗어남 | 항목 이름, 모델(또는 기본) 이름 (D14) | 입력 값, 주소, 키 |
| 모르는 샘플링 항목 | 항목 이름 (D14) | 입력 값, 주소, 키 |
- 설정의 Debug와 모든 설정 오류의 Display·Debug에 base_url 호스트와 키가 없다.

## AC
1. Given 주석이 든 정상 설정이 있을 때, When 읽으면, Then 엔드포인트·모델·샘플링·시간 값이 읽히고 빠진 값은 기본값이 된다.
2. Given 엔드포인트 이름 중복(대소문자만 다른 이름은 허용), 모델 이름 중복, 없는 엔드포인트를 가리키는 모델, 지원하지 않는 `kind`와 `reasoning`, 범위를 벗어나거나 모르는 샘플링 항목, 모델 `extra`의 예약 키(`model`, `messages`, `stream`, `tools`)가 각각 있을 때, When 읽으면, Then 각각 거부되고 오류에는 이름만 있고 값·주소·키는 없다.
3. Given 자격 파일 `api_keys`에 엔드포인트 이름이 있을 때 그 키를 쓰고, 이름이 없거나 빈 문자열이거나 자격 파일이 없으면 키 없음이다(테스트).
4. Given 엔드포인트에 `api_key` 칸이 있을 때, When 읽으면, Then 엔드포인트 이름과 "키는 credentials.jsonc에 둔다"는 안내만 담은 설정 오류로 거부하고 `api_key` 값은 오류에 없다.
5. JSONC 문법 오류는 줄 번호만 알리고, 설정의 Debug와 모든 설정 오류에 base_url 호스트와 키가 없으며, `agent-snap.example.jsonc`는 자리표시자만 담고 읽으면 검증을 통과한다(테스트).
