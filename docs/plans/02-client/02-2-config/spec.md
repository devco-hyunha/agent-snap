# 02-2 설정 읽기와 검증: 명세

- 상위 문서: [plan.md](plan.md)

## 입력과 출력
- 파일 접근 책임: 02-2가 설정 폴더에서 파일(`agent-snap.jsonc`, `credentials.jsonc`)을 읽어 텍스트를 얻는 일을 맡고, 02-1은 그 텍스트를 받아 해석한다.
- 설정 읽기
  - 입력: 사용자 설정 폴더 경로. 폴더 안의 `agent-snap.jsonc`를 읽는다. 주석(`//`, `/* */`)과 마지막 쉼표를 허용한다.
  - 출력: 검증을 통과한 설정(언어, 엔드포인트 목록과 각 엔드포인트 아래 모델 목록, 샘플링 기본값, 시간·재시도 값). 실패하면 설정 오류. 내부 진실은 중첩(`endpoints[].models`)으로 보관한다. 모델 조회는 헬퍼(펼친 뷰)로 하며 AC에 타입 이름은 두지 않는다(D20).
- 키 정하기
  - 입력: 검증된 엔드포인트, 자격 파일 `credentials.jsonc`에서 읽은 이름별 값([02-1](../02-1-secrets/spec.md), 자격 파일이 없으면 없음).
  - 출력: 그 엔드포인트의 비밀 값 또는 "키 없음".
- 사용자 설정 폴더 위치 계산
  - 입력: 운영체제 관례에 필요한 환경 정보(주입받는다).
  - 출력: 폴더 경로. Windows는 Roaming AppData 아래 `agent-snap`, 그 밖은 XDG 관례를 따른다. 읽기 기능과 나눠 둬서 폴더 경로를 직접 줄 수 있다.
- `agent-snap.example.jsonc`: 저장소 루트에 두는 자리표시자만 담은 예시 파일. 읽으면 검증을 통과한다.

## 설정 항목
- `target_language`: 기본 `ko`.
- `endpoints`: `name` 필드를 가진 배열(객체 맵 아님). 생략·빈 배열 허용, 생략은 `[]`로 정규화(D20).
- 엔드포인트(D10, D20): 필수 `name`, `base_url`(`/v1`까지 포함한 주소로 문서·예시에서 안내, 비밀 값 래퍼로 담음), `kind`(`openai`, `openrouter`, `ollama`, `vllm`, `llamacpp`, `lmstudio` 중 하나 — strata 전용 kind 없음). 그 아래 `models` 배열. 키 칸(`api_key`, `api_key_env`)은 없다.
- `base_url` 검증(D19): scheme을 `http`/`https`로만 한정하고, 빈 문자열·앞뒤 공백·끝 슬래시를 허용하지 않는다. `/v1` 경로 여부는 검증하지 않는다. scheme을 제외한 나머지(호스트·경로)는 검사하지 않는다.
- 모델(`endpoints[].models`, D20): 필수 `name`, 서버에 보낼 `id`(둘 다 trim 후 비면 거부). 선택 `sampling`, `reasoning`(`off`, `low`, `medium`, `high`), `extra`(D15). 모델에 `endpoint` 칸은 없다.
- `extra`: 공통 옵션에 없는 값을 하위 객체까지 담는 객체. 요청 본문에 합치는 일은 [02-5](../02-5-transport/spec.md)가 한다.
- `sampling`: 샘플링 기본값. 모델별 값이 있으면 모델별 값이 앞선다(적용은 [02-7](../02-7-model-select/spec.md)). 루트에서 생략하면 기존 기본(항목별 서버 기본을 따름).
- 지원하는 샘플링 항목은 `temperature`, `top_p`, `max_tokens` 세 가지다(D14).
- `http`: 시간·재시도 값. 키 이름은 `retries`, `backoff_min`, `backoff_max`, `retry_after_max`, `connect_seconds`, `header_wait_seconds`, `stream_idle_seconds`만 인정한다. 옛 toml 이름 호환 없음. 생략 시 아래 기본값(D20).

## 기본값
- `target_language`: `ko`.
- `endpoints`/`models` 생략: `[]`.
- `reasoning`, `extra`: 없으면 요청에 아무것도 더하지 않는다.
- 샘플링: 모델별 값과 `sampling` 어디에도 없는 항목은 기본값을 두지 않는다. 요청 본문에서 빼서 서버 기본값을 따른다(D14).
- `http`(설정으로 바꿀 수 있고, 빠지면 아래 값이 된다)
  - `retries` 3
  - `backoff_min` 1초
  - `backoff_max` 30초
  - `retry_after_max` 60초
  - `connect_seconds` 10초
  - `header_wait_seconds` 300초
  - `stream_idle_seconds` 120초

## 동작 규칙
### 정상
- 사용자 설정 폴더 정하는 순서(D19): 환경 변수 `AGENT_SNAP_CONFIG_DIR`에 값이 있으면 그 폴더를 쓴다. 값이 없으면 운영체제 관례 폴더(Windows는 Roaming AppData 아래 `agent-snap`, 그 밖은 XDG 관례)를 쓴다.
- 정상 설정을 읽으면 엔드포인트(그 아래 모델 포함), 샘플링, 시간 값이 읽힌다.
- 빠진 값은 위 기본값이 된다. `endpoints`/`models`가 비어 있어도 읽기는 통과한다(“고를 모델 없음”은 02-7·CLI).
- 자격 파일에 이름이 없는 엔드포인트를 허용한다(키가 필요 없는 로컬 서버).
- 모델 이름과 서버에 보낼 id는 서로 다를 수 있다.
- 다른 엔드포인트끼리는 같은 모델 별칭을 허용한다. 유일성은 같은 엔드포인트 안에서만 본다(D20).
- 엔드포인트·모델 `name`은 trim한 뒤 저장·자격 매칭에 쓴다(D20).
- 알 수 없는 칸(거부 칸이 아닌 것)은 무시한다(02-1과 동일 취지).

### 키 정하기(D10)
- 자격 파일 `api_keys`에 그 엔드포인트 이름(trim한 값)이 있고 빈 문자열이 아니면 그 키를 쓴다. 이름은 적힌 그대로 쓰며 대소문자와 `-`·`_`를 구분한다.
- 이름이 없거나 빈 문자열이거나 자격 파일이 없으면 "키 없음"이다. 이때 요청은 Authorization 헤더 없이 간다([02-5](../02-5-transport/spec.md)).

경계
- `temperature`는 0 이상 2 이하, `top_p`는 0 초과 1 이하, `max_tokens`는 1 이상 정수여야 한다(D14).
- 엔드포인트·모델 이름은 trim 후 비어 있지 않은 문자열이어야 하며 `/`를 포함하면 안 된다(D20 추천 가정: 선택 키 `엔드포인트이름/모델이름` 구분자). 자격 파일의 키 이름으로 적힌 그대로 쓰이므로 그 밖의 형식 제한은 없다.
- 설정 폴더 경로를 받아 읽는 기능은 폴더 위치 계산과 독립이라 임시 폴더로 시험할 수 있다.

거부(이름만 밝힌 오류)
- 엔드포인트에 `api_key` 또는 `api_key_env` 칸이 있는 경우: 값은 읽지도 출력하지도 않고, 엔드포인트 이름과 "키는 credentials.jsonc에 둔다"는 안내만 담은 설정 오류로 거부한다(D10, D20).
- 최상위 옛 `models`가 있는 경우: “모델은 endpoints[].models에” 안내로 거부한다(D20).
- 모델에 `endpoint` 칸이 있는 경우: 모델 이름(또는 위치)만 밝히고 거부한다(D20).
- `base_url` 값이 검증(D19)을 통과하지 못한 경우: 엔드포인트 이름만 밝히고 입력 값·주소·키는 출력하지 않는다.
- 엔드포인트 이름이 중복된 경우(trim 후). 정확히 같은 문자열일 때만 중복이다(`Local`과 `local`은 서로 다르다).
- 같은 엔드포인트 안에서 모델 이름이 중복된 경우(trim 후).
- 엔드포인트·모델 `name` 또는 모델 `id`가 trim 후 빈 경우.
- 엔드포인트·모델 `name`에 trim 후 `/`가 있는 경우: 이름만 밝힌 설정 오류로 거부한다(D20).
- `kind`가 지원하는 여섯 값이 아닌 경우: 엔드포인트 이름만 밝히고 값은 출력하지 않는다.
- `reasoning`이 네 값이 아닌 경우: 모델 이름만 밝힌다.
- `extra`에 클라이언트가 채우는 키(`model`, `messages`, `stream`, `tools`)가 있는 경우: 모델 이름과 그 키 이름만 밝힌다(D15).
- JSONC 문법 오류: 줄 번호만 알린다.
- 샘플링 항목이 범위를 벗어난 경우: 항목 이름과 모델(`sampling`이면 "기본") 이름만 밝혀 거부한다. 값은 출력하지 않는다(D14).
- 지원하지 않는 샘플링 항목: 항목 이름만 밝혀 거부한다(D14).

## 오류 종류와 담는 것
| 오류 | 담는 것 | 담지 않는 것 |
|---|---|---|
| 엔드포인트 이름 중복, 빈 이름, 이름에 `/` | 엔드포인트 이름 | base_url, 키 |
| 모델 이름에 `/` | 엔드포인트 이름, 모델 이름 | 주소, 키 |
| 엔드포인트에 `api_key`·`api_key_env` 칸 있음 | 엔드포인트 이름, 안내 문구 | `api_key`/`api_key_env` 값, base_url |
| 최상위 옛 `models` | 안내 문구 | 모델 값, 주소, 키 |
| 모델에 `endpoint` 칸 있음 | 모델 이름(또는 위치) | 주소, 키 |
| 같은 엔드포인트 안 모델 이름 중복, 빈 name/id | 엔드포인트 이름, 모델 이름 | id 값(빈 id 제외 시), 주소, 키 |
| `kind` 값 오류 | 엔드포인트 이름 | 입력 값, 주소, 키 |
| `base_url` 값 오류(D19) | 엔드포인트 이름 | 입력 값, 주소, 키 |
| `reasoning` 값 오류 | 모델 이름 | 입력 값, 주소, 키 |
| `extra` 예약 키 | 모델 이름, 예약 키 이름 | `extra`의 값, 주소, 키 |
| 파일 접근 실패 | 폴더 경로와 파일 이름 | 파일 내용, base_url, 키 |
| JSONC 문법 오류 | 줄 번호 | 줄 내용, 값 |
| 샘플링 범위 벗어남 | 항목 이름, 모델(또는 기본) 이름 (D14) | 입력 값, 주소, 키 |
| 모르는 샘플링 항목 | 항목 이름 (D14) | 입력 값, 주소, 키 |
- 설정의 Debug와 모든 설정 오류의 Display·Debug에 base_url 호스트와 키가 없다.

## AC
1. Given 주석이 든 정상 설정(중첩 `endpoints[].models`)과 설정 폴더 지정 환경 정보가 있을 때, When 읽으면, Then 환경 변수 `AGENT_SNAP_CONFIG_DIR`에 값이 있으면 그 폴더를 쓰고 값이 없으면 운영체제 관례 폴더를 쓰며, 엔드포인트·모델·샘플링·시간 값이 읽히고 빠진 값·생략 `endpoints`/`models`는 기본값(`[]` 포함)이 된다.
2. Given 엔드포인트 이름 중복(대소문자만 다른 이름은 허용), 같은 엔드포인트 안 모델 이름 중복, 엔드포인트에 `api_key`·`api_key_env` 칸, 최상위 옛 `models`, 모델의 `endpoint` 칸, trim 후 빈 엔드포인트·모델 이름·모델 id, trim 후 `/`가 든 엔드포인트·모델 이름, 지원하지 않는 `kind`와 `reasoning`, 범위를 벗어나거나 모르는 샘플링 항목, `base_url` 값 오류(scheme이 `http`/`https`가 아니거나 빈 문자열·공백·끝 슬래시), 모델 `extra`의 예약 키(`model`, `messages`, `stream`, `tools`)가 각각 있을 때, When 읽으면, Then 각각 거부되고 오류에는 이름만 있고 값·주소·키는 없다. 다른 엔드포인트에 같은 모델 별칭이 있어도 허용한다.
3. Given 검증된 엔드포인트와 자격 파일의 이름별 값이 있을 때, When 키 정하기를 하면, Then `api_keys`에 trim한 엔드포인트 이름이 있으면 그 비밀 값, 이름이 없거나 빈 문자열이면 없음, 자격 파일이 없으면 없음으로 매핑된다(테스트).
4. Given 엔드포인트에 `api_key` 또는 `api_key_env` 칸이 있어 AC 2의 거부가 일어날 때, When 오류를 확인하면, Then AC 2의 거부 항목에 해당 칸 값이 없음을 확인한다.
5. Given JSONC 문법이 틀린 설정과, 그 설정의 Debug와 모든 설정 오류의 Display·Debug와, 저장소 루트의 `agent-snap.example.jsonc`가 각각 있을 때, When 읽고 확인하면, Then (1) JSONC 문법 오류는 줄 번호만 알리고 값·줄 내용은 없다(테스트), (2) 설정의 Debug와 모든 설정 오류의 Display·Debug에 base_url 호스트와 키가 가려진다(가림 확인 테스트 포함), (3) `agent-snap.example.jsonc`는 자리표시자만 담고, 읽으면 검증을 통과한다(테스트).
