# 09 종단 검증

- 상태: planned

## 목적
test 분할과 코딩 과제로 감시·교정의 최종 효과를 확인한다.

## 범위(In)
- 세 구성을 각 3회 실행한다: 감시 끔, 규칙만, 규칙과 판정 모델.
- 채점은 독립 라벨러와 과제 테스트로 한다. 판정기 자신으로 채점하지 않는다.
- 보고서 `docs/reports/09-e2e.md`: 잠정 목표 대비 표, 실패 사례, 다시 볼 점, 재현 명령 한 줄.

## AC
1. test 해시가 작업 06 기록과 같다.
2. 구성별 범주별 최종 발생률, 상대 감소율, 부트스트랩 신뢰구간이 있다.
3. 추가 토큰, 시간, 과제 성공률을 비교한다.
4. 목표 충족·미달을 그대로 적는다. 미달이면 원인과 다음 작업 제안을 적는다.
5. 확인 전용 서브에이전트가 보고서 수치를 원시 결과에서 다시 계산해 일치한다.

## DoD
AC 충족, 검증 통과, 리뷰 PASS.
