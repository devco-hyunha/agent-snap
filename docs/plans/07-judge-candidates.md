# 07 판정 모델 후보 목록

- 상태: planned

시작 전 확인: 판정 모델의 권한 범위를 사용자에게 다시 확인한다(2026-10-28 사용자 요청).

## 목적
판정 모델 후보를 내려받지 않고 용량과 라이선스까지 확인한 목록으로 정리한다.

## 범위(In)
- `docs/eval/JUDGE_CANDIDATES.md`: 후보마다 이름, 저장소 URL, 종류, 파일 형식, 실제 파일 목록 기준 크기, 라이선스(출처 링크), 게이트 여부, Rust 런타임 경로(ort, candle, llama.cpp 바인딩), 예상 CPU 메모리, 맡을 범주.
- 기준선은 작업 05의 규칙 감시기다. 말만 바꾼 반복처럼 규칙이 못 잡는 경우를 맡을 후보를 우선한다.
- 라이선스는 표시만 하고, 그것만으로 탈락시키지 않는다. 1GB 초과와 게이트 모델만 제외한다.
- 런타임 후보에서 ollama는 제외한다(감싸지도 않는다). llama.cpp나 CPU에서 도는 런타임만 본다.

## 비범위(Out)
다운로드와 실행.

## 조사
- 주제: 소형 언어 식별, 문장 임베딩 기반 반복 탐지, 소형 분류기·생성 모델을 판정기로 쓴 연구.

## 반영할 연구
- 후보 축: 로마자 언어 이탈은 소형 언어 식별기(GlotLID 2310.16248), 말만 바꾼 반복은 소형 다국어 문장 임베딩(Sentence-BERT 1908.10084). 한자·가나는 유니코드 규칙이 먼저 맡는다.
- 구조는 규칙 → 소형 CPU 모델 → 필요할 때만 큰 판정의 다단계로 한다(2512.19011). 크기 기준 참고(Llama Guard 3-1B-INT4 2411.17713).

## AC
1. 1GB 이하 후보가 5개 이상이고, 세 범주 각각을 맡을 후보가 2개 이상이다.
2. 각 후보의 크기와 라이선스에 출처 링크가 있다.
3. 다운로드는 0건이다.
4. 추천 순위와 이유가 있다. RESEARCH.md에 조사 항목이 있다.
5. 사용자가 목록을 승인했다.
