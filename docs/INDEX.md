- `PLAN.md`: 기획 개요, 전제, 작업 목록.
- `DECISIONS.md`: 결정 **인덱스**(짧으면 전문, 길면 요약·정본 링크·다시 볼 점).
- `decisions/`: 결정 **상세 정본**(D9·D10·D20·D21·D22 등).
