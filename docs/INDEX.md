# 문서 목록

- [기획 개요](PLAN.md)에서 기획별 작업과 현재 상태를 확인합니다.
- `DECISIONS.md`: 결정 **인덱스**(짧으면 전문, 길면 요약·정본 링크·다시 볼 점).
- `decisions/`: 결정 **상세 정본**.
- `RESEARCH.md`: 조사 **인덱스**(핵심 한 줄, 적용 위치·미적용, 상태, 상세 링크).
- `research/`: 조사 **상세**(기획 순번별 파일).
- `plans/`: 기획 정본. 계획 번호 01~09. 하위 폴더는 `<기획>/<세부>-<작업명>/plan.md·spec.md·tasks.md`.
- `tasks/`: 상세 작업 문서(T-파일)와 위임 문서. git 제외.
- `reviews/`: 독립 리뷰 기록. git 제외.
- `notes/`: 로컬 전용 메모. git 제외.

## 문서 규칙

- 상태 줄은 갈아엎고 2,000자 이하.
- 계획·유지보수 문서는 `plans/maintenance/<기획 순번>/`에 두고 새 계획 번호를 남발하지 않습니다.
- 하네스 문서는 AGENTS.md 마커 블록과 `harness/` 정본이 정본이고, 프로젝트 오버레이는 마커 바깥에 둡니다.
