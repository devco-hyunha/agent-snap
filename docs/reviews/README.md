# 코드리뷰 PASS 기록

코드리뷰 PASS 기록(`docs/reviews/`)이 있어야 커밋합니다. 이 규칙은 `AGENTS.md`의 규칙으로만 지키며, 기계적 강제(훅)는 없습니다(D51).

## 기록 형식

- 파일 이름: `docs/reviews/<작업번호>-<순번>.md` (예: `03-1.md`)
- 필수 줄: 기록 파일 안에서 줄 머리(앞 공백 없이)에 `판정: PASS`(미달이면 `판정: 미달`) 줄이 있어야 합니다.
- 파일 안에서 마지막 `판정:` 줄이 `판정: PASS`여야 합니다. 앞쪽에 PASS가 있어도 뒤쪽에 `판정: 미달`이 있으면 인정하지 않습니다.
- 본문: 체크리스트 항목별 결과, 문제 목록(파일:라인, 심각도), 메인이 확인한 근거와 고친 내용.
- `대상 해시:` 줄은 더는 필요 없습니다. 과거 기록에 남아 있어도 그대로 둡니다.
