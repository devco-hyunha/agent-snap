# 한국어 교정 하네스

한국어 문서, 스킬, 보고 문장을 제안, 승인, 적용 순서로 교정한다.

## 1. 검사 항목

- 맞춤법과 띄어쓰기
- 사용자 대상 문장의 존댓말 일관성(-요, -습니다). 반말은 쓰지 않는다.
- 번역투(예: "~에 의해", "~을 통해" 과다 사용)와 불필요하게 긴 문장
- 모호한 표현과 중복(같은 말 반복)
- 영어 약어와 용어는 처음 나올 때 한국어 풀이를 붙인다. 예: AC(인수 조건)
- 코드, 경로, 명령, 식별자, frontmatter 키(name, description)는 원문 그대로 둔다. 고치지 않는다.

## 2. 절차 (제안, 승인, 적용)

1. 대상 파일 목록을 받는다.
2. 서브에이전트(모델은 하네스 문서 8절을 따른다)에게 교정 제안만 쓰게 한다. 파일은 수정하지 않는다. 결과는 "줄 번호, 원문, 수정문, 이유" 목록으로 낸다.
3. 메인이 목록을 사용자에게 보여주고 승인을 받는다.
4. 승인된 항목만 기록 서브에이전트(자체 포함 프롬프트)가 적용한다.
5. 적용 후 frontmatter와 파일 줄 수가 유지됐는지는 확인 전용 서브에이전트가 확인한다.

서브에이전트가 없는 도구는 하네스 문서 3절의 대체 규칙을 따른다.

## 3. 금지

- 의미를 바꾸는 교정을 하지 않는다. 의심스러우면 제안만 하고 적용하지 않는다.
- 승인 없이 적용하지 않는다.

프로젝트 규칙 우선은 하네스 문서 1절을 따른다. 승인·안전 규칙은 하네스 문서 5절을 따른다. (하네스 문서: harness/HARNESS.md)
