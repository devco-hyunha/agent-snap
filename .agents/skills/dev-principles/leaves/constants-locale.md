# 13. 상수와 사람 문구 분리

- 정의: 사람이 읽는 문구와 코드용 상수는 제품 로직 파일에 묻지 않고 역할 파일로 둔다. `locale`/`localeKey`는 역할 이름이며 언어별 문구 묶음 라이브러리 강제가 아니다. 실제 경로·파일명은 프로젝트 오버레이가 정한다.
- 사람 문구(화면·에러·안내 등): 사용 횟수와 무관하게 로직 밖 `locale`/`localeKey` 역할 파일로 분리 **권장**. locale을 쓰지 않는 프로젝트에서도 같다.
- 코드용 상수(박힌 숫자·내부 설정값): **2곳 이상**이면 역할 파일로 분리. 한곳만이면 동거 허용(단 SRP와 충돌하면 `solid` 우선).
- 이름: 식별자·파일 역할은 `locale` / `localeKey`를 쓴다(`message`는 정본이 아님).
- 리뷰: 권고 미준수=minor. 이미 locale을 쓰는 프로젝트에서 사람 문구를 로직에 그대로 두면 major.
- 위반: 사람 문구·상수를 로직에 몰아넣고 YAGNI로 분리를 거부한다. 모든 문구·상수를 파일 하나에 몰아넣는다.
