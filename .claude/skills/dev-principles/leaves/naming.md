# 6. 이름과 함수

- 정의: 이름만 보고 동작을 알 수 있어야 하고, 함수는 한 가지 일만 하며 재사용 가능하게 분리한다.
- 기준: 구현 전에 기존 함수를 먼저 찾아 재사용한다. 이름에 "그리고"를 넣어야 설명되면 쪼개고, 여러 곳에서 쓰일 순수 함수·보조 함수는 본문 파일에 묻어 두지 말고 해당 역할 폴더의 별도 파일로 분리해 export한다. 불리언 매개변수 대신 별도 함수나 명명된 옵션을 쓰고, 깊은 중첩보다 early return을 쓴다.
- 위반: 기존 유틸 함수를 확인하지 않고 같은 파일 안에 함수를 또 만들거나, `process(data, true, false)`처럼 호출부에서 의미를 알 수 없게 쓴다.
